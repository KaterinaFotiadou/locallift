Die virale Kampagne
#FindeSanxia

Ein Format, das Nutzer selbst nachbauen - und damit die App weiterverbreiten, ohne dass wir einen Cent dafür zahlen.

Hook-Satz für jedes Video
„Google zeigt dir das nicht. Aber hier lebt Taiwan wirklich."
Warum das funktioniert
  • Klare Vorher/Nachher-Mechanik (der Algorithmus liebt das)
  • Reproduzierbar - jeder kann es kopieren (= virale DNA)
  • App-Nutzung ist der Inhalt (Nutzer = Werbeträger)

Kapitel 05 — Kreislauf
06 / 09
Engagement-Kreislauf

Die App selbst ist der Marketingkanal.

Unsere bestehende Stempel-Challenge wird zum viralen Motor: Nutzer sammeln digitale Stempel an realen Orten in Sanxia.

Komplettes Set → kostenloser handgefärbter Indigo-Beutel von einem lokalen Shop. Ein „Stempel teilen"-Button postet automatisch auf Instagram und TikTok.

Jeder Nutzer wird zum Werbeträger. Das Marketing-Budget bleibt klein — die Nutzer produzieren Inhalte für uns.
